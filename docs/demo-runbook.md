# Nixor Connect demo runbook

Use an approved non-production identity and a test entity. Stop if the deployment
does not pass its health checks; do not substitute static screenshots or fake data.

1. Start Google SSO and confirm the approved institutional identity reaches Home.
2. Open an entity or project server and add an eligible person using a picker.
3. From a message, create an accountable action, assign it, then acknowledge and update it as the recipient.
4. Have the reviewer accept or request changes, then record a formal decision.
5. Long-press or right-click a message, select **Report**, complete the short form, and retain the returned report number.
6. Open Reports and confirm the reporter-safe status. Through a permitted reviewer account, confirm a bounded encrypted evidence snapshot exists; do not browse ordinary DM history.
7. Demonstrate an approved bot interaction and the health/status command.
8. Repeat the message report and action acknowledgement on Android only after the verified App Link OAuth flow has passed.

For each run record the build SHA, artifact hash, account role, time, and any failed network request with its correlation ID. Never record Matrix access tokens or cookies.
